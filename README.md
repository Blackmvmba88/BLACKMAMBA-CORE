# BLACKMAMBA CORE

BLACKMAMBA CORE is a layered music intelligence core for catalog awareness, metrics, vocal evidence, and strategic recommendations.

It is not a music app.  
It is not a dashboard.  
It is not an isolated vocal analyzer.

It is a connection node between creation, interpretation, and public response.

Suno creates possibilities.  
BLACKMAMBA CORE understands them.  
SoundCloud responds with numbers.  
The artist decides.

## v0.1 Architecture Skeleton

This first version focuses on models, contracts, pure functions, examples, and tests.

Rules:

- TypeScript first.
- Pure functions before UI.
- No scraping yet.
- No auth yet.
- No private APIs yet.
- No heavy generative AI yet.
- Models, contracts, and metrics first.
- Modular and testable by default.
- Prepared for React/Vite, Express, and Firebase later.

## Layers

1. Song Registry
2. Data Model
3. Metrics Engine
4. Vocal Runtime Contracts
5. Suno Connector Contract
6. SoundCloud Connector Contract
7. Recommendation Engine
8. Music Graph
